# 『Claude Code セキュリティ入門』練習用アプリ

書籍『Claude Code セキュリティ入門』（著者：AI設計工房／KEI Publishing）の、第2章〜第6章で使う練習用アプリです。

本の手順どおりに、このアプリを Claude Code に点検させ、指摘を読み、直させ、もう一度点検する練習ができます。

## ⚠️ はじめにお読みください

- **わざと安全の穴を入れた、練習用のアプリです。** インターネットに公開しないでください。自分のアプリにコードを流用しないでください。
- **中に入っている鍵やパスワードは、すべて偽物です。** 本物のサービスにはつながりません。
- **このアプリは動かせません。** コードを読んで点検する練習のためのものです。
- **点検の結果は、毎回少し変わります。** 本の答え合わせと、穴の数や番号が完全には一致しないことがあります。違っても手順は同じです。

## ダウンロードのしかた

1. このページの上のほうにある、緑の「**Code**」ボタンを押します。
2. 出てきたメニューのいちばん下、「**Download ZIP**」を押します。
3. ダウンロードした zip ファイルをダブルクリックして開きます。
4. 開いたフォルダの中にある **`security-test-app`** フォルダに入ってから、Claude Code を起動します（本の第2章）。

上の手順のかわりに、次のリンクを開いても同じ zip ファイルをダウンロードできます。

https://github.com/kei-publishing/claude-code-security-practice/archive/refs/heads/main.zip

> `security-test-app` フォルダには、Mac の Finder では表示されないファイル（`.env.local`）も入っています。点検で使うので、消さないでください。

## ダウンロードできないとき

本の第2章に、Claude Code にこの練習用アプリを作ってもらう頼み方を載せています。その方法でも、同じ手順で練習できます。
